# md → docx 排版（数模论文定稿）

> 本技能为团队约定，具体赛事要求优先。仅面向竞赛论文，不自动用于期刊或学位论文。


## 1. 总体流程

运行前需具备 Pandoc 3.x、Python 和 `python-docx`；独立安装本技能后，可在技能目录运行 `python -m pip install -r requirements.txt`。所需字体见第 3 节，字体不随技能分发。

1. 确认 md 遵循标题层级约定（`#`=论文标题、`##`=一级标题、`###`=二级标题、`####`=三级标题；列表"1./（1）"为正文文本）。
2. `pandoc 论文.md -o 论文_raw.docx`（需自行安装 Pandoc 3.x 并加入 PATH；图片路径按执行目录解析）。
3. `python scripts/apply_docx_layout.py 论文_raw.docx 论文.docx`（页面/样式/字体/表格/图片/公式编号）。
4. 用 Word 导出 PDF 目检（核对清单见 `references/workflow.md`）。

## 2. 页面

- A4（210×297mm）；上下 72pt，左右 76.5pt。

## 3. 字体（正文与表格）

- 中文：宋体 小四 正体。
- 数学变量（英文字母）：Times New Roman 小四 斜体。
- 数学符号（Δ、β、=、× 等希腊字母与运算符）：Cambria Math 小四 斜体。
- 名称/缩写/函数/算法/常量/单位：正体（TNR/宋体）。
- 数字：Times New Roman 正体。
- 判定口诀：变量斜体，其余（常量/单位/函数/算法/中文/缩写）正体。

## 4. 标题与摘要

- 论文标题：黑体 三号（16pt），居中。
- 摘要标题："摘　要"（两空格），黑体 四号（14pt），居中。
- 关键词："关键词："黑体 小四 + 内容宋体 小四，整行加粗。

## 5. 正文

- 两端对齐；首行缩进 2 字符（24pt）；**1.25 倍行距**；无分割线；数字前后不加空格。

## 6. 标题层级

- 一级：黑体 四号（14pt）居中，段前段后 6 磅，编号"一、二、…"。
- 二级：黑体 小四（12pt）左对齐，段后 6 磅，编号"1.1、…"。
- 三级：黑体 小四（12pt）左对齐，编号"1.1.1、…"。
- 其余编号（"1.、2."或"（1）、（2）"）用正文文本。

## 7. 图片 / 表格 / 图表标题 / 公式

- 图片：居中、无缩进。
- 表格：学术三线表、居中、无缩进、内容宋体居中、**默认五号（10.5pt）、单倍行距**；列宽按内容自适应，表头/数字/化学式尽量单行，断行规则见 7.1。
- 图表标题：宋体 + Times New Roman，五号（10.5pt），加粗，居中，需编号；表标题在表上，图标题在图下。
- 公式：规范数学形式；连续/同类公式用花括号（cases）；居中；全文右端编号 (1)、(2)、…（md 中不手写编号）。
- 公式写作：**公式内避免出现汉字或完整英文单词作量**（如不写"效率"、average、total），量只用规范符号（单字母/希腊字母，可带上下标）表示；需要中文/全称说明的放在公式后的"式中"解释。

> 坑点：表格单元格段落必须同时清除 `firstLineChars`（与 `firstLine` 一起置 0），否则会继承 Normal 样式的 2 字符首行缩进，导致表头/数字被拆行。

## 7.1 表格排版与断行规则

1. 表格应保持整齐、紧凑、美观，避免不必要的空白和断行。
2. 表头文字、数字、英文字母及其组合应尽量保持在同一行。
3. 完整的数字、英文单词、英文缩写、数学符号及符号组合不得随意拆分到两行。
4. 对于较长的表头或单元格内容，应优先通过调整列宽、单元格边距和换行位置优化排版。
5. 只有在确实无法避免的情况下才进行换行，并应选择语义自然的位置断行（如中文标点、英文单词边界）。
6. 避免出现标题或表头只剩一个数字、字母、英文单词或短语孤立在下一行的情况。
7. 表格默认采用五号字（10.5pt）、单倍行距；若表格内容过密，可适当缩小字号（如小五 9pt），但不得影响可读性。
