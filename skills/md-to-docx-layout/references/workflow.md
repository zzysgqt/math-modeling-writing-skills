# md → docx 转换与排版流程

## 0. 工具

- Pandoc 3.x（需自行安装并加入 PATH；使用 `pandoc --version` 确认）
- python-docx（后处理脚本 `scripts/apply_docx_layout.py`）

## 1. 准备 md

- 按"md 标题层级约定"使用 `#`/`##`/`###`/`####`。
- 图片：`![说明](图片路径)`；图标题写在图片下方。
- 表格：Markdown 表格语法；表标题写在表格上方。
- 公式：行内 `$...$`；独立公式 `$$...$$`；连续/同类公式用 `\begin{cases}...\end{cases}`；**不要手写公式编号**。
- 公式内不写汉字或完整英文单词作量（量用符号 + 上下标；需要说明的放公式后"式中"）。
- 正文数字前后不加空格。

## 2. pandoc 转换

```
pandoc 论文.md -o 论文_raw.docx
```

注意：pandoc 按当前工作目录解析图片相对路径，建议在 md 所在目录执行，或使用绝对路径。

## 3. 后处理排版

```
python apply_docx_layout.py 论文_raw.docx 论文.docx
```

脚本完成：
1. 页面：A4（210×297mm），上下 72pt，左右 76.5pt。
2. 样式：Normal（宋体/TNR 小四、两端对齐、首行缩进 2 字符、1.25 倍行距）、Heading 1~4（标题单倍行距）、Caption（五号加粗居中，自动创建）。
3. 摘要标题"摘　要"（两空格）、关键词行（黑体小四 + 宋体小四 + 加粗）。
4. 内联字体分类：中文宋体、变量 TNR 斜体、名称/缩写/函数/算法/单位/常量正体、数学符号 Cambria Math 斜体。
5. 表格三线表、居中、内容居中宋体。
6. 图片段落居中、无缩进。
7. 独立公式（oMathPara）居中 + 右端编号 (1)、(2)、…。

## 3.5 常见坑（已实测）

- **图片必须独占段落**：md 中图片行前后要各留一个空行，否则 pandoc 会把图片内联进相邻文字段落。图注用 `![图N 标题](路径)` 的 alt 文本，pandoc 会生成 Image Caption 样式；脚本会自动把普通文本"表N/图N…"短行也排成五号加粗居中。
- **主题字体覆盖**：pandoc 样式常带 `eastAsiaTheme` 等主题属性，会覆盖显式设置的"黑体/宋体"（曾出现标题变 DengXian）。脚本已自动清除这些主题属性。
- **公式编号**：md 中不要手写公式编号；独立公式（$$…$$）由脚本统一居中并在右端编号 (1)(2)…。行内公式不编号。
- **中文斜体**：中英文混排时（如"DNA片段"），判词务只按 ASCII 字母分词，避免把中文并入英文而斜体；中文恒为正体。
- **文字颜色**：pandoc 默认样式可能带颜色（如标题蓝色）；脚本会统一把所有文字颜色设为黑色。
- **切片正则偏移**：用 `re.match(pattern, text[i:])` 时，`m.end()` 是相对切片的偏移，必须 `i += m.end()`，否则会跳回造成死循环/内存耗尽（T13/T18/T21 分支曾踩坑）。
- **标题/图注/表注**：一律不斜体；参考文献条目需在 md 中用空行分隔（否则 pandoc 合并成一段），脚本会去掉其首行缩进。
