# 数模论文"符号说明与公式解释"写作规范（文字版）

> 依据：3 篇国奖论文（2017B 一等奖、A15010142 月球软着陆、C050 蔬菜定价）、官方模版与《格式说明》52–53 页、以及本团队的排版约定（宋体小四 + Times New Roman 斜体 + Cambria Math 斜体）。
> 适用：撰写或修改数模论文的"符号说明与名词定义"一节，以及正文公式后的变量解释。

---

## 一、总体定位

1. "符号说明"是一张**精炼字典**，不是全部符号的清单。国奖论文通常只列 6–15 行（官方模版预留 8 行），本团队复杂论文最多约 17 行。
2. 位置固定：模型假设之后、模型建立之前，单独一节（如"四、符号说明与名词定义"）。
3. 形式：三线表（仅顶线、底线、表头下线），列建议为 `符号 | 说明 | 单位`。
4. 读者定位：评阅人需要"查阅"的是贯穿全文的核心变量；临时变量应就地解释。

## 二、国奖论文写法总结（规则来源）

### 1. 什么进总表（三条规则）
- **全局复用**：贯穿多个问题/多个模型、读者需要回头查的核心变量。
- **带单位的物理量**：有明确物理/生态含义和单位的量优先；无单位的参数（系数、阈值）一般不进。
- **一族一行**：用下标族压缩行数（如 `S_ij` 一行覆盖所有 i,j）。

### 2. 什么只在公式后解释（四类）
- 单式参数/回归系数（q₁~q₄、β₀、β₁）。
- 模型局部指标：只在某一个小节定义使用的派生量。
- 统计/随机项：误差 ε、随机效应 u/v、方差 σ²。
- 作者设定的阈值（δ=0.10、τ=0.05）。

### 3. 首现必解释（即使进表）
格式说明明确："下文中首次出现这些变量时也要进行解释，不然会降低文章的可读性。"国奖论文实例：p、s 在总表里，正文首次出现仍写"设定价为 p，用户限额总和为 s"。

### 4. 局部参数多的做法：局部小表
C050 在 Holt-Winters 模型处放 6 行"指标解释"小表（m、α、β、γ、x̂、x），不进全局总表。

### 5. 其他规范
- 排序按逻辑分组（通用下标 → 物理量 → 速率 → 派生指数）。
- 单位列统一：无量纲用"—"；`年⁻¹` 用上标。
- 表中符号字体、下标格式与正文一致。

## 三、判定规则（决策清单）

| 判定问题 | 是 → 进总表 | 否 → 留在公式后 |
|---|---|---|
| 该问/该模型的核心输入或输出？ | ✓ | 辅助派生量 |
| 被 ≥2 个问题 或 ≥3 个小节复用？ | ✓ | 仅单小节内高频 |
| 出现在摘要/结论/结果表中？ | ✓ | 只出现一次 |
| 带明确物理意义和单位？ | ✓ | 系数/阈值/误差项 |
| 一族可用下标合并为一行？ | ✓ 合并 | 零散单式参数 |

**负向规则（永远不进总表）**：求和/循环/编码用的临时下标、作者自己设的阈值、统计误差项。

## 四、字体规范（团队约定）

| 内容 | 字体 | 字号 | 字形 |
|---|---|---|---|
| 中文解释 / 名词定义 | 宋体 | 小四 (12pt) | 正体 |
| 英文字母 / 单词（变量、Olson/Xylem/Bark） | Times New Roman | 小四 | 斜体 |
| 数学符号（M、Δ、∈、=、Rₜ=Mₜ/M₀） | Cambria Math | 小四 | 斜体 |
| 单位（g、mm、%、—、年⁻¹） | Times New Roman / 宋体 | 小四 | 正体 |
| 表头 | 宋体 | 小四 | 加粗 |

执行细则：
1. **符号列（变量符号）**整体按"数学符号"用 Cambria Math 斜体；夹带的中文（"、"、"木质素"）用宋体正体。
2. **含义说明列**：中文宋体正体；英文单词与单字母变量（Olson、Xylem、Bark、t、j、k…）用 Times New Roman 斜体；数学运算符与表达式（∈、=、/、{}、Rₜ=Mₜ/M₀）用 Cambria Math 斜体。
3. **单位列用正体**（单位不是变量，不斜体）；英文单位（g、mm、%）用 Times New Roman，中文（年）用宋体，`年⁻¹` 的 `-1` 用上标。
4. **名词定义列表**与含义说明列同样处理（中文宋体、英文 TNR 斜体、数学表达式 Cambria Math 斜体），引导句"名词定义："加粗。
5. **正文公式解释部分不需要统一改造**：正文公式是 OMML 对象（默认 Cambria Math），行内变量已是斜体，自成体系；全文统一改造风险大且非本表要求。

## 五、名词定义

- 术语类名词（非符号）在表后列 3–6 条简短列表，例如：Olson 指数衰减模型、根芯(Xylem)/根皮(Bark)、质量残留率、碳组分净释放率、主导调控/均衡调控、留一物种交叉验证。
- 若表后不列名词，就把章节标题改为"符号说明"。

## 六、写作工作流（改进版）

> 针对"先解释全部变量、再把出现≥3次的整理进总表并删除公式后解释"这一思路的评价：
> - **可行部分**：先就地解释、后统一整理，能保证每个符号至少定义一次，符合国奖论文的实际形成过程。
> - **需修正**：① 频率高≠该进总表（单小节内高频的 Δk、RII 应留在公式后；出现 3 次的 k_single 是核心输出必须进表），应加"覆盖几个问题/小节"维度；② 提升后**不要删除首次解释**，只压缩后续重复（"含义同前"）；③ Word 公式是 OMML，普通"查找"数不到公式内符号，频次统计要用 XML/PDF 解析。

推荐流程：
1. **起草**：每个新符号在首次出现处用"设/记/其中/式中"就地解释。
2. **登记**：维护符号登记表——符号 | 含义 | 单位 | 首次出现位置 | 覆盖小节/问题 | 次数。
3. **提升**：双条件——(重要性 或 跨 ≥2 问题/≥3 小节) 且 带单位物理量 → 进总表。
4. **压缩**：保留首次解释，后续重复解释改为"含义同前"。
5. **收尾校验**：见第七节。

## 七、校验清单

写作前：
- [ ] 每个新符号首次出现处是否已就地定义？
- [ ] 符号登记表是否覆盖全文？

写作后（总表）：
- [ ] 行数 ≤ ~17，逻辑分组，三线表，单位列统一（"—"表示无量纲）。
- [ ] 表内每个符号在正文确实出现且写法（含下标）一致。
- [ ] 正文每个公式中的符号，要么在总表、要么在公式后定义过。
- [ ] 一"族"一行，族内含义一致。
- [ ] 回归系数、阈值、误差项、随机效应没有混进总表。

字体（docx）：
- [ ] python-docx 检查 run：中文=宋体/12pt/正体；英文=Times New Roman/12pt/斜体；数学=Cambria Math/12pt/斜体；单位=正体；表头=宋体加粗。
- [ ] Word 导出 PDF，pdfplumber 逐字符核验字体名；Cambria Math 斜体以变换矩阵 c≈0.3333 确认。
- [ ] 目检三线表结构、无溢出、下标正常。

## 八、常见错误与修改建议

| 常见问题 | 建议 |
|---|---|
| 总表 20+ 行，把局部指标也塞进去 | 只留核心变量，局部指标移回公式后或做局部小表 |
| 族符号解释过于复杂（如"设 p∈{...}"） | 精简为一句，族内含义合并 |
| 漏了跨问题符号（如 k_Xylem/k_Bark、(木质素:N)₀） | 用符号登记表核对覆盖范围 |
| 单位列不规范（`-`、`年-1`） | 统一"—"、`年⁻¹` 上标 |
| 同一符号每道公式后都重复一整句解释 | 首次详细，后续"含义同前" |
| 只按"出现次数≥3"决定进表 | 用"重要性 + 跨小节/跨问题"双条件 |
| 提升后删掉公式后的解释 | 保留首次解释，只压缩重复 |
| 下标用 Unicode 字符或纯文本 | 用 Word 下标（vertAlign subscript） |

## 九、实操要点（docx 修改）

- 用 python-docx 重建表格行时，深拷贝一行数据行作为模板，保留 trPr/tcPr/pPr（居中、垂直居中、行距 252）。
- 每个 run 的 rPr 按"宋体 / Times New Roman / Cambria Math"分别构造，附加 `w:sz=24`（小四）、斜体 `w:i`、`w:vertAlign`（上下标）。
- 中文与拉丁/数学混排时按字符分类拆分 run：CJK（含全角标点）→ 宋体；拉丁字母 → TNR 斜体；运算符/希腊字母/数学表达式 → Cambria Math 斜体。
- 表格样式用"三线表"（顶线、底线、表头下线），不要加列线。
- 修改前先备份原 docx。
