# 数模论文符号说明与公式解释写作规范

> 本技能为团队约定，具体赛事要求优先。仅面向竞赛论文，不自动用于期刊或学位论文。


## 1. 核心原则

- 把"符号说明"表当作**精炼字典**而非全部符号清单：只列全局复用、带单位的核心变量。国奖论文通常 6–15 行，最多约 17 行。
- 进了总表的符号，正文**首次出现时仍要解释**一遍（用"设 / 记 / 其中 / 式中"），不能只靠查表。
- 公式后的解释负责"就地定义"：单式参数、局部指标、统计项、阈值**永远只在公式后解释**。
- 局部参数多的小节，用**局部小表**（如 Holt-Winters 参数表）承载，不进全局总表。

## 2. 判定：进总表 vs 只在公式后解释

| 判定问题 | 是 → 进总表 | 否 → 留在公式后 |
|---|---|---|
| 是该问/该模型的核心输入或输出？ | ✓ | 辅助派生量 |
| 被 ≥2 个问题 或 ≥3 个小节复用？ | ✓ | 仅单小节内高频 |
| 出现在摘要/结论/结果表中？ | ✓ | 只出现一次 |
| 带明确物理意义和单位？ | ✓ | 系数/阈值/误差项 |
| 一族可用下标合并为一行？ | ✓ 合并成一行 | 零散单式参数 |

永远不进总表：回归系数（β、q_i）、误差项 ε、随机效应 u/v、方差 σ²、作者设定阈值（δ、τ）、求和/循环/编码临时下标。

## 3. 符号表格式

- 三线表，列：`符号 | 说明 | 单位`（建议加单位列）。
- 逻辑分组排序：通用下标 → 物理量 → 速率 → 派生指数。
- 一"族"一行，如 `C₀、Cₜ（C₀,ⱼ、Cₜ,ⱼ）`。
- 单位列统一：无量纲用"—"；`年⁻¹` 用上标；单位不斜体。
- 说明文字精简，且与正文实际用法一致。

## 4. 字体规范（团队约定）

| 内容 | 字体 | 字号 | 字形 |
|---|---|---|---|
| 中文解释 / 名词定义 | 宋体 | 小四 (12pt) | 正体 |
| 英文字母 / 单词（变量、Olson/Xylem/Bark） | Times New Roman | 小四 | 斜体 |
| 数学符号（M、Δ、∈、=、Rₜ=Mₜ/M₀） | Cambria Math | 小四 | 斜体 |
| 单位（g、mm、%、—、年⁻¹） | Times New Roman / 宋体 | 小四 | 正体 |
| 表头 | 宋体 | 小四 | 加粗 |

- 符号列整体按"数学符号"用 Cambria Math 斜体；其中夹带的中文（"、"、"木质素"）用宋体正体。
- 含义说明列：中文宋体正体；英文单词与单字母变量用 TNR 斜体；数学表达式用 Cambria Math 斜体。
- 正文公式解释部分：**不需要统一改造**（公式为 OMML/Cambria Math，行内变量已斜体）。

## 5. 名词定义

- 术语类名词（非符号）在表后列 3–6 条简短列表，例如：Olson 指数衰减模型、根芯(Xylem)/根皮(Bark)、质量残留率、净释放率、主导调控/均衡调控、留一物种交叉验证。
- 若表后不列名词，就把章节标题改为"符号说明"。

## 6. 写作工作流（推荐，替代"频次≥3"法）

1. 起草时对每个新符号在**首次出现处就地解释**（设/记/其中/式中）。
2. 维护符号登记表：符号 | 含义 | 单位 | 首次出现位置 | 覆盖小节/问题 | 次数。
3. 用**双条件**提升进总表：(重要性 或 跨 ≥2 问题/≥3 小节) 且 带单位物理量。不要只用"出现次数≥3"。
4. 提升后**保留首次解释**、压缩后续重复解释（写"含义同前"）。
5. 收尾校验：总表 ≤~17 行、逻辑分组、三线表、单位列统一、表内符号在正文确实出现且写法一致、正文公式中每个符号要么在表要么在公式后定义过。

## 7. 校验流程

- 用 python-docx 检查每个 run 的 `font.name` / `eastAsia` / `italic` / `subscript` / `size`。
- 用 Word COM 导出 PDF：`Documents.Open` + `ExportAsFixedFormat(path, 17)`。
- 用 pdfplumber 逐字符核验字体名：SimSun / TimesNewRomanPS-ItalicMT / CambriaMath；Cambria Math 斜体以字符变换矩阵 `c≈0.3333` 确认。
- 目检三线表结构、无溢出、下标正常。
